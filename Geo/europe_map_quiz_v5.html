    Cómo se juega

    Selecciona un lugar de la lista y haz clic en el mapa. Puedes volver a hacer clic para mover la marca.

    • Zoom: rueda del ratón, botones + / − o pellizco.
    • Mover: arrastra el mapa. ⤢ muestra todo el mapa.
    • Teclado: enfoca el mapa y usa las flechas para mover el cursor (con Mayús va más rápido), Intro o Espacio para colocar, + / − para el zoom y 0 para ver todo.
